# Git-панель в боковой колонке чата — короткий дизайн

**Зачем:** видеть, что в выбранном пространстве есть незафиксированные изменения git, сколько их и что именно поменялось, не выходя из чата.

**Цели:**
- Между блоками spaces и files — новый блок в том же стиле: строка иконок (как на скриншоте VS Code). Пока одна — git.
- На иконке git — синий кружок со счётчиком изменённых файлов выбранного пространства; нет изменений — нет кружка; не git-репозиторий — иконка серая.
- Клик по git раскрывает/сворачивает внутри этого же блока отдельное дерево изменённых файлов (папки → файлы, буква статуса M/U/D/A/R). Дерево files не меняется никак.
- Клик по файлу в списке — в области редактора вкладка сравнения в две колонки с общей прокруткой: слева версия из HEAD (удалённые строки красным), справа текущий файл (добавленные зелёным). Новый файл — слева пусто, удалённый — справа пусто.
- Счётчик обновляется: после шагов агента, по ↻, при смене пространства, и периодически (несколько секунд), пока окно открыто.

**Не цели (пока):** кнопка коммита, stage/unstage, редактирование в окне сравнения, остальные иконки.

**Подходы:** (А) счётчик на папке в spaces + пометки в дереве; (Б) счётчик в строке состояния; (В) отдельный блок с иконками и счётчиком. Пользователь выбрал В: строка иконок, git раскрывает своё дерево изменений; files не трогается (уточнение пользователя).

**Решения Claude:** окно сравнения только для чтения; бинарные/нечитаемые файлы — сообщение вместо сравнения; diff строк считается на Python (difflib) по `git show HEAD:path` и файлу на диске.
