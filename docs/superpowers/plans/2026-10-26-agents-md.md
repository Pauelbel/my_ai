# AGENTS.md: правила папки — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ася подмешивает `AGENTS.md` активной папки в системный промпт; вики `my_web_notes` получает свои правила и предупреждения сборки.

**Architecture:** В `agent_core` — чтение `<project_dir>/AGENTS.md` при каждой сборке промпта и блок «Правила папки» в `SYSTEM_PROMPT`. В `my_web_notes` — файл `AGENTS.md` и функция проверок в `build.py`, печатающая предупреждения в stdout.

**Tech Stack:** Python 3.14, markdown (вики), Ollama qwen3.5:9b (агент).

**Spec:** `docs/superpowers/specs/2026-10-26-agents-md-design.md`

## Global Constraints

- Имя файла — константа `AGENTS.md`, ищется только в корне `config.project_dir`.
- Текст обрезается до `config.output_limit` символов.
- Нет файла — блока в промпте нет совсем (не пустой заголовок).
- Slug латиницей через дефис, папки-разделы по-русски, `title` по-русски.
- Предупреждения формата `предупреждение: <путь от notes/>: <что не так>`; сборку не останавливают.
- Ничего не коммитить (правило пользователя). Тестового набора в проектах нет — проверка скриптами.
- Не создавать `__init__.py`.

## Review Focus

- `AGENTS.md` в кодировке с BOM или пустой — пустой файл даёт отсутствие блока, BOM не попадает в промпт (`utf-8-sig`).
- Фигурные скобки в `AGENTS.md` (`{title}`) — не ломают `SYSTEM_PROMPT.format` (подставлять уже отформатированный текст, не через format-строку файла).
- Неизвестный `status` сейчас валит сборку `SystemExit` — становится предупреждением со статусом `draft`.
- Slug с кириллицей или пробелом — предупреждение «имя файла латиницей через дефис».
- Битая `[[ссылка]]` — предупреждение с именем ссылки (сейчас она молча выкидывается из `links`).
